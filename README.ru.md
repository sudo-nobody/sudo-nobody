# sudo -u nobody

```console
$ id
uid=65534(nobody) gid=65534(nogroup)
$ sudo -u nobody ./ship --quiet
```

Права root, характер nobody. Делаю небольшие инструменты, которые решают одну задачу и не мешают
жить. Без лица и без личного бренда — профиль говорит кодом.

## Принципы

- **Скучное лучше умного.** Код читают гораздо чаще, чем пишут.
- **Один инструмент — одна задача.** Композиция вместо списка фич.
- **Правило пяти минут.** Если проект не запускается по README за пять минут — он не готов.
- **Минимум привилегий — в коде и в эго.**
- **Маленькие диффы, скромные заявления.**
- **Тихие релизы.** Меньше анонсов, больше работающего софта.
