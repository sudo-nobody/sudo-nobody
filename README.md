# sudo -u nobody

```console
$ id
uid=65534(nobody) gid=65534(nogroup)
$ sudo -u nobody ./ship --quiet
```

Root privileges, nobody attitude. I build small tools that do one job well and then get out of the
way. No face, no personal brand — the code is the profile.

## Principles

- **Boring beats clever.** Code gets read far more often than it gets written.
- **One tool, one job.** Composition over feature lists.
- **The five-minute rule.** If a project cannot be run from its README in five minutes, it is not
  finished.
- **Least privilege — in code and in ego.**
- **Small diffs, small claims.**
- **Ship quietly.** Fewer announcements, more working software.
